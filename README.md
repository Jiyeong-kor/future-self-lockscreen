# Future Self

> 내가 무엇을 해야 하는지가 아니라, 왜 그걸 하기로 했는지를 잊지 않게 해주는 앱

평소의 생각과 회고를 쌓고, 시간이 지난 뒤 서로 연결하거나 종합하면서 무엇을 왜 중요하게 생각했는지 다시 찾는 개인 기록 앱입니다. 최초의 이유와 이후의 의미 변화를 함께 보존합니다.

사용자는 생각만 남기고 나갈 수 있습니다. 분류, 연결, 목표와 행동 계획은 기록의 완료 조건이 아닙니다. 잠금화면은 사용자가 선택하고 공개 승인한 문장을 표시하는 후속 출력 기능입니다.

## 현재 상태

개발 중입니다. 제품 기획, 코드 작성, 자동 테스트, 네이티브 기기 검증을 구분합니다. 자세한 범위와 남은 검증은 [구현 상태](docs/IMPLEMENTATION_STATUS.md)에 정리합니다.

현재 작성된 코드:

- React Native 0.87.0 Community CLI 프로젝트와 iOS/Android 네이티브 골격
- TypeScript 도메인 규칙과 단위 테스트
- OP-SQLite SQLCipher 설정, 보안 키 저장소 연동, 초기 스키마와 migration 실행기
- 빠른 기록 저장, 최근 기록 홈, 기록 목록
- 분류 없는 의미 카드 작성과 목록, 상세 읽기
- 기록 메뉴에서 선택한 원문을 출처로 연결하는 의미 카드 생성
- 출처 revision 존재 확인, 불변 원문 조회, 카드와 최초 기록 및 검색 색인의 원자적 저장
- 의미 카드 커서 페이지 조회, 로딩 및 오류 상태, 중복 저장 방지
- 실제 SQLite 통합 테스트와 화면 흐름 테스트
- GitHub Actions의 typecheck, test, lint와 별도 의존성 검사

아직 iOS 네이티브 빌드와 실기기 검증을 완료하지 않았습니다. Node SQLite 테스트 통과는 SQLCipher, Keychain, 파일 보호와 실제 화면 동작의 검증을 대신하지 않습니다. 실제 개인 데이터가 아니라 가상 데이터를 사용해 개발합니다.

다음 구현은 네이티브 실행과 개인정보 보호 검증, 기록과 의미 카드의 revision 편집, 관계와 Why Trail 연결입니다. Synthesis, 블록 연결, 잠금화면 위젯, 백업과 멀티디바이스를 이미 완성한 상태는 아닙니다.

## 정보 구조

최상위 탐색은 네 영역입니다.

```text
홈 | 기록 | 의미 | 설정
```

| 영역 | 제품 설계상 역할 |
| --- | --- |
| 홈 | 빠른 기록, 현재 문장, 최근 기록, 선택적 이전 맥락 |
| 기록 | 타임라인, 검색, 회고와 여러 기록 같이 보기 |
| 의미 | 의미 카드, Why Trail, 블록 연결, 선택적 갈등 검토 |
| 설정 | 앱 잠금, 알림, 위젯, 백업 및 복원, 내보내기 |

회고, Synthesis, 시간 여행과 전체 Meaning Map은 필요한 순간에만 진입합니다. 위 표는 전체 제품의 설계이며 모든 기능이 구현된 것은 아닙니다.

## 제품 원칙

- 현재 완전 무료이며 결제, 구독, 광고와 데이터 판매를 사용하지 않습니다.
- 제품에 AI 기능을 넣지 않습니다.
- 기록할 때 분류, 연결, 목표화와 행동화를 강제하지 않습니다.
- 분류되지 않은 의미 카드, 해결하지 않은 갈등과 다시 열지 않은 기록도 정상 상태입니다.
- 후회뿐 아니라 잘한 선택, 욕망, 발견, 전환점과 깨달음을 남길 수 있습니다.
- 하나의 목표와 행동에 여러 이유를 연결하고, 그 이유가 변한 과정을 보존합니다.
- 수정은 새 revision으로 저장하며 과거의 근거를 소급 변경하지 않습니다.
- 연결 개수, 미분류 개수, 그래프 완성도와 연속 사용 일수를 성취 지표로 만들지 않습니다.
- 사용자의 자기해석이나 정체성 표현을 제품이 교정하지 않습니다.
- 갈등 검토와 의미 재확인은 사용자가 선택하는 기능입니다.
- 대표 잠금화면 문장은 사용자의 명시적 선택으로만 바뀝니다.
- 문장 공개 승인, 시각적 스타일 변경과 의미 재확인은 서로 구분합니다.
- 민감한 과거 기록을 임의로 다시 보여주거나 복귀 시 밀린 작업을 만들지 않습니다.
- 개인 DB와 위젯에 필요한 공개용 데이터를 분리합니다.
- 검색, 과거 시점 보기, 암호화 백업과 데이터 이동권을 장기 제품 요구사항으로 유지합니다.
- 실행 일정은 필요한 경우에만 외부 도구와 연결하며 할 일 및 습관 추적 앱으로 확장하지 않습니다.
- local-first와 프라이버시를 지키는 멀티디바이스 지원을 지향합니다.
- Android는 공통 도메인 안정화 이후 지원합니다.
