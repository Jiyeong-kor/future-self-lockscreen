# Future Self 정보 구조

- 상태: UX 구현 기준
- 작성일: 2026-09-05
- 상위 기준: `docs/PRD.md`
- 관련 문서: `docs/USER_FLOWS.md`, `docs/SCREEN_STATES.md`

이 문서는 Future Self의 화면 계층, 기본 탐색 구조, 사용자에게 노출할 용어와 기능 배치를 정의한다. 도메인 규칙이나 보안 규칙과 충돌하면 PRD와 canonical schema를 우선한다.

## 1. IA 원칙

1. 사용자는 앱을 열자마자 구조를 관리하지 않고 생각을 기록할 수 있어야 한다.
2. 기록, 의미, 잠금화면은 연결되지만 서로 다른 작업으로 구분한다.
3. 회고, Synthesis, 시간 여행, 전체 Meaning Map처럼 사용 빈도가 낮은 기능을 최상위 탭으로 올리지 않는다.
4. 미분류, 미연결, 오래 방치된 상태를 미완료로 표현하지 않는다.
5. 내부 도메인 용어를 초기 화면에 그대로 노출하지 않는다.
6. 사용자가 원하는 순간에만 깊은 구조로 들어갈 수 있게 Progressive Disclosure를 적용한다.
7. 모든 주요 흐름은 행동 계획을 만들지 않고 종료할 수 있어야 한다.

## 2. 최상위 탐색

하단 탭은 4개로 구성한다.

```text
홈 | 기록 | 의미 | 설정
```

### 2.1 홈

가장 자주 쓰는 진입점이다.

목적:

- 바로 한 줄 기록
- 현재 잠금화면 문장 확인
- 최근 기록 다시 열기
- 안전하게 재노출 가능한 소수 Review 확인
- 장기간 미사용 후 원할 때 이전 맥락 다시 보기

홈을 대시보드나 미처리함으로 만들지 않는다.

### 2.2 기록

사용자가 남긴 원문과 회고를 찾는 공간이다.

포함:

- 통합 검색
- 시간순 기록
- CaptureEntry
- ReflectionSession / ReflectionItem
- SynthesisInsight
- 기간, 종류, 태그, 상태 필터
- 여러 기록 선택 후 `같이 보기`
- 과거 표현 검색 opt-in

`기록`은 Inbox가 아니다. 정리되지 않은 기록 개수를 강조하지 않는다.

### 2.3 의미

사용자가 자신에게 중요하다고 판단해 별도의 의미 객체로 남긴 카드를 보는 공간이다.

포함:

- 의미 카드 목록
- 분류되지 않은 Meaning Card
- Motive, Vision, Goal, Practice, Commitment 필터
- 카드 상세
- 관계 상세
- Why Trail
- Focus Board
- Block Tray
- 갈등 관계와 선택적 Trade-off Reflection
- 후속 전체 Meaning Map

분류되지 않은 Meaning Card는 정상 상태이며 별도의 `정리 필요` 영역으로 보내지 않는다.

### 2.4 설정

제품 사용 환경, 개인정보, 데이터 이동을 관리한다.

포함:

- 앱 잠금
- 알림
- 잠금화면 Widget 설정 안내
- 백업과 복원
- 사람이 읽을 수 있는 내보내기
- 재노출 제외 설정
- 시스템 통합
- 접근성 관련 설정 안내
- 개인정보 및 제품 정보

## 3. 홈 화면 구조

### H-01 홈

위에서 아래 순서:

1. 현재 대표 잠금화면 문장
2. 한 줄 빠른 기록 입력
3. 최근 기록
4. Review 후보 최대 3개
5. 필요할 때만 `이전 맥락 다시 보기`
6. 회고 진입점

표시할 것이 없는 영역은 공간을 남기지 않고 사라진다.

### H-02 현재 문장 상세

현재 activeAnchor를 누르면 진입한다.

포함:

- 실제 표시 문장
- 원본 Commitment 보기
- 왜 이 문장을 선택했는지 보기
- 공개 승인 상태
- 배경과 배치 변경
- 표현 새로 쓰기
- 다른 승인 문장으로 교체
- activeAnchor 해제

`아직 중요한가요?`를 강제로 묻지 않는다.

### H-03 빠른 기록

홈 인라인 입력을 기본으로 한다. 긴 입력이 필요한 경우 확장 화면으로 전환한다.

필수 입력은 본문뿐이다.

저장 후 기본 동작은 홈으로 돌아가는 것이다.

선택적으로:

- 의미 카드로 남기기
- 기존 의미에 연결
- 나중에 같이 보기 위해 선택

을 열 수 있지만 저장 직후 자동으로 띄우지 않는다.

## 4. 기록 영역

### R-01 기록 목록

기본은 최근순 타임라인이다.

카드에 필요한 정보만 표시한다.

- 짧은 본문
- 날짜
- 유형이 있는 경우 유형
- 회고 소속 여부

연결 여부나 미분류 여부를 경고 배지로 표시하지 않는다.

### R-02 통합 검색

기록과 의미 객체를 한 번에 검색할 수 있다.

검색 결과 그룹:

- 기록
- 회고
- Synthesis
- 의미 카드

과거 revision은 사용자가 `과거 표현까지 검색`을 켠 경우에만 포함한다.

### R-03 Reflection 목록

회고 세션을 기간과 제목으로 보여준다.

새 회고는 사용자가 원할 때 생성한다. 정기 회고를 강제하지 않는다.

### R-04 Reflection 상세

질문별 작성 진행률을 표시하지 않는다.

답하지 않은 질문은 누락이 아니라 비어 있는 선택 항목이다.

### R-05 같이 보기 선택 모드

기록 목록에서 여러 항목을 선택해 Synthesis workspace로 보낸다.

선택 대상:

- CaptureEntry
- ReflectionItem
- 기존 SynthesisInsight

선택 개수를 성취나 진행률로 취급하지 않는다.

### R-06 Synthesis workspace

선택한 기록을 한 화면에서 비교하고 사용자가 새 해석을 작성한다.

기본 결과는 SynthesisInsight 저장이다.

저장 후 Meaning Card 생성이나 행동 연결을 요구하지 않는다.

## 5. 의미 영역

### M-01 의미 카드 목록

기본 정렬은 최근 수정 또는 사용자가 선택한 정렬 기준으로 제공한다.

카드 종류:

- 분류 없음
- 이유
- 미래상
- 목표
- 실천
- 원칙

내부 코드의 `motive`, `vision`, `goal`, `practice`, `commitment`를 그대로 교육하지 않아도 된다.

분류 필터는 탐색 도구이며 모든 카드에 분류를 요구하는 수단이 아니다.

### M-02 의미 카드 상세

포함:

- 현재 표현
- 선택적 분류
- 연결된 의미
- 출처
- OriginMoment
- MeaningCheckIn
- revision history
- Why Trail 진입
- 수정, 종료, 병합, 삭제

분류되지 않은 카드에서도 상세 화면의 대부분을 사용할 수 있어야 한다.

### M-03 Focus Board

휴대전화에서 구조적 연결을 만드는 기본 작업 공간이다.

중앙에 선택한 카드 하나를 두고 필요한 관계 슬롯만 보여준다.

예시 사용자 문구:

- 왜 중요하지?
- 무엇과 이어지지?
- 어떤 미래와 관련 있지?
- 무엇을 돕고 있지?
- 무엇과 충돌하지?

DnD와 탭 연결을 모두 제공한다.

### M-04 Why Trail

현재 항목에서 과거 이유와 출처로 거슬러 올라가는 읽기 중심 화면이다.

전체 그래프가 아니라 현재 질문에 필요한 경로를 우선한다.

### M-05 관계 상세

관계 자체의 생성 시점, 메모, MeaningCheckIn, 이력을 볼 수 있다.

`conflicts_with` 관계에서는 사용자가 원할 때만 Trade-off Reflection을 연다.

### M-06 Trade-off Reflection

두 항목 중 어느 쪽이 옳은지 앱이 판단하지 않는다.

선택적으로 남길 수 있는 내용:

- 둘 다 원하는 이유
- 현재 시점의 우선순위
- 선택에 따른 포기 비용
- 나중에 다시 보고 싶은 시점
- 아무 결론도 내리지 않음

마지막 상태 역시 정상 완료이다.

### M-07 전체 Meaning Map

후속 고급 화면이다.

기본 탐색 수단이 아니다.

- viewport 기반 로딩
- 전체 그래프 완성도 표시 금지
- 배치 자체를 성취로 만들지 않음
- Focus Board에서 할 수 없는 탐색을 보조하는 용도

## 6. 잠금화면 관련 화면

잠금화면은 최상위 탭으로 두지 않는다. 홈의 현재 문장 또는 Commitment 상세에서 진입한다.

### L-01 Projection 작성

내부 Commitment를 그대로 노출하지 않고 공개용 표현을 별도로 작성한다.

### L-02 공개 승인

실제 외부에 표시될 문구를 보여주고 승인받는다.

문구 내용이 바뀌면 새 approval이 필요하다.

### L-03 스타일 편집

같은 승인 문장의:

- 배경
- 위치
- 정렬
- 크기
- 여백
- 줄바꿈

을 바꾼다.

텍스트가 바뀌지 않으면 공개 승인을 다시 요구하지 않는다.

### L-04 Widget 안내

앱이 Widget 설치를 자동 완료한다고 표현하지 않는다. iOS 잠금화면 사용자화에서 추가하는 방법을 안내한다.

## 7. 시간 여행

### T-01 revision history

한 객체의 표현 변화 목록이다.

### T-02 현재와 과거 비교

현재 revision과 과거 revision을 나란히 보여준다.

### T-03 특정 시점 보기

특정 날짜에 어떤 노드와 관계가 유효했는지 재구성한다.

시간 여행은 기본 홈에 자동 노출하지 않는다.

## 8. 복귀와 Review

### V-01 Review 카드

홈에서 최대 3개만 보여준다.

반드시 `왜 지금 보이는지` 설명할 수 있어야 한다.

### V-02 이전 맥락 다시 보기

장기간 미사용 후에도 강제 화면이 아니다.

안전한 후보가 있을 때 홈에 작은 진입점을 둘 수 있다.

사용자가 눌렀을 때만 이전 activeAnchor나 재노출 가능한 의미를 보여준다.

## 9. 사용자에게 노출하는 용어

초기 UX에서는 다음 표현을 우선한다.

| 내부 용어 | 사용자 표현 |
| --- | --- |
| CaptureEntry | 기록 |
| MeaningNode | 의미 카드 |
| unclassified MeaningNode | 의미 카드 또는 분류 없음 |
| Motive | 이유 |
| Vision | 미래상 |
| Goal | 목표 |
| Practice | 실천 |
| Commitment | 원칙 |
| Synthesis | 같이 보기 / 새롭게 발견한 생각 |
| Provenance | 어디서 시작됐는지 / 출처 |
| MeaningCheckIn | 의미 변화 / 다시 생각해본 기록 |
| conflicts_with | 서로 충돌함 |
| activeAnchor | 현재 잠금화면 문장 |

전문 용어는 설명 화면이나 개발 문서에서만 사용해도 된다.

## 10. 전역 진입점

다음 기능은 특정 탭에 갇히지 않게 한다.

- 빠른 기록: 홈 및 후속 App Intent
- 검색: 기록 탭 기본 + 홈 상단 검색 진입 가능
- 현재 잠금화면 문장: 홈
- 앱 잠금 인증: 모든 private 화면 앞단

## 11. 딥링크와 시스템 진입

App Intent, Shortcut, Action Button 등에서 앱을 열 경우:

- 인증이 필요한 상태에서는 개인 화면을 먼저 렌더링하지 않는다.
- 빠른 기록 진입은 작성 화면으로 바로 이동할 수 있다.
- 개인 기록 ID를 Spotlight에 자동 공개하지 않는다.

## 13. IA 완료 기준

- 사용자가 앱 구조를 몰라도 홈에서 기록하고 종료할 수 있다.
- 모든 깊은 기능은 사용자의 명시적 진입으로 열린다.
- 분류되지 않은 의미 카드가 다른 카드와 동등하게 탐색 가능하다.
- 행동 계획을 만들지 않아도 모든 주요 흐름을 정상 종료할 수 있다.
- 잠금화면 공개 승인과 내부 의미 기록이 분리된다.
- Review와 복귀 UX가 backlog를 만들지 않는다.
- 전체 Meaning Map 없이도 핵심 제품 가치를 사용할 수 있다.
