# Future Self 수익화 정책

- 상태: 현재 정책 확정
- 최근 갱신: 2026-09-05

## 1. 현재 정책

Future Self는 당분간 모든 사용자에게 무료로 제공한다.

현재 버전에는 다음을 두지 않는다.

- 무료 체험 종료 후 결제
- 일회성 구매
- 구독
- 기능별 유료 잠금
- 광고
- 사용자 데이터 판매

앱의 핵심 기록, 검색, Why Trail, Synthesis, 잠금화면 Projection, 백업과 복원, 멀티디바이스 관련 기능을 수익화를 이유로 임의 제한하지 않는다.

## 2. 개인정보와 수익화 경계

향후 수익화를 다시 검토하더라도 다음은 유지한다.

- 개인 기록 기반 광고 타기팅 금지
- 사용자 데이터 판매 금지
- 기록·회고·동기 내용에 따른 가격 차별 금지
- 데이터 내보내기나 삭제를 유료 기능으로 만들지 않음

## 3. 향후 재검토

수익화는 제품이 충분히 안정되고 공개 운영 비용과 유지보수 비용을 실제로 판단할 수 있는 시점에 다시 결정한다.

과거에 검토했던 1년 무료 체험, 일회성 구매, 이후 구독 전환안은 현재 정책이 아니며 보류한다.

향후 유료화로 전환할 경우 기존 무료 사용자의 권리, 데이터 접근, 구매 복원, grandfathering 여부를 별도 정책으로 명시한 뒤 적용한다.

## 4. 구현 원칙

현재 Phase 1과 이후 제품 구현에서는 결제 시스템을 선행 구현하지 않는다.

StoreKit 상품, entitlement, paywall, 구독 상태 관리 코드는 실제 유료화 결정이 다시 내려진 뒤 추가한다.
