# Future Self 수익화 정책

- 상태: 제품 전략 확정
- 확정일: 2026-09-05
- 적용 기준일: 공개 출시일

## 1. 기본 원칙

Future Self의 수익화는 광고나 사용자 데이터 판매에 의존하지 않는다.

사용자의 개인 기록, 관계, 동기, 목표, 회고 데이터는 수익화를 위해 판매하거나 광고 타기팅에 사용하지 않는다.

## 2. 출시 후 1년 무료 체험

사용자는 처음 이용을 시작한 뒤 1년 동안 제품을 무료로 체험할 수 있는 방향을 채택한다.

정확한 StoreKit 상품 구성은 구현 시점의 App Store 정책과 기능을 다시 확인해 결정한다.

Apple App Review Guidelines는 비구독 앱도 기간제 체험 후 비소모성 In-App Purchase를 통해 전체 기능을 잠금 해제하는 구조를 허용한다. 따라서 초기 일회성 구매 모델은 이 방향과 양립하도록 구현한다.

무료 체험 시작일, 복원, 재설치, 기기 변경에도 체험 권리가 일관되도록 App Store receipt 및 Apple이 허용하는 식별·검증 수단을 사용한다. 단순 로컬 날짜만으로 체험 권리를 판정하지 않는다.

## 3. 공개 출시 후 5년 이내의 구매 모델

공개 출시일부터 5주년 전까지는 다음 모델을 사용한다.

```text
1년 무료 체험
→ 체험 종료
→ 일회성 유료 구매
→ 구매 후 지속 사용
```

일회성 구매는 복원 가능한 비소모성 구매 entitlement로 구현하는 것을 기본 방향으로 한다.

구매자는 해당 entitlement를 잃지 않는다.

## 4. 공개 출시 5주년 이후

공개 출시 5주년부터 신규 수익 모델을 구독으로 전환한다.

전환 이후 신규 사용자의 기본 경로는 다음과 같다.

```text
1년 무료 체험
→ 체험 종료
→ 구독
```

구독의 월간·연간 구성과 실제 가격은 공개 전 별도 상업 설정으로 정한다.

## 5. 기존 일회성 구매자 grandfathering

구독 모델로 전환하기 전에 일회성 유료 구매를 완료한 사용자는 grandfathered lifetime 사용자로 취급한다.

규칙:

- 이후 구독료를 요구하지 않는다.
- 앱 재설치나 기기 변경 시 구매 복원이 가능해야 한다.
- 구독 모델로 변경했다는 이유로 기존 주요 기능을 잠그지 않는다.
- grandfathered entitlement는 영구적으로 보존한다.
- 구독 전환 UI에서 기존 구매자에게 잘못된 결제 화면을 노출하지 않는다.

Apple App Review Guidelines도 기존 앱을 구독 모델로 변경할 때 이미 전체 잠금 해제 등을 구입한 사용자가 기존 주요 기능을 계속 이용할 수 있어야 한다고 안내한다.

## 6. 전환 시점의 체험 사용자

공개 출시 5주년 시점에 아직 1년 무료 체험 중이며 일회성 구매를 완료하지 않은 사용자에게 어떤 결제 경로를 적용할지는 구독 전환 준비 단계에서 확정한다.

권장 기본안은 사용자가 체험을 시작할 당시 안내받은 결제 경로를 존중하여, 전환 전에 체험을 시작한 사용자에게는 기존 일회성 구매 옵션을 유지하는 것이다.

이 결정은 Phase 1 구현을 막지 않는다.

## 7. 앞으로 확정할 상업 설정

제품 구조와 별개로 공개 전에 다음 값을 정한다.

- 일회성 구매 가격
- 구독 가격
- 월간, 연간 또는 둘 다 제공할지
- 국가·지역별 가격
- 5주년 전 체험 시작 사용자에 대한 전환 경로 최종 확정

## 8. 금지하는 수익화 방식

- 광고 SDK를 통한 수익화
- 개인 기록 기반 광고 타기팅
- 사용자 데이터 판매
- 기록·회고·동기 내용에 따른 가격 차별
- 사용자가 자신의 데이터를 내보내거나 삭제하기 위해 추가 결제를 요구하는 구조
