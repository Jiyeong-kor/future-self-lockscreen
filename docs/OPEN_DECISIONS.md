## 1. 확정된 제품 전략

### 포지셔닝

외부 포지셔닝의 중심 문장:

> 내가 무엇을 해야 하는지가 아니라, 왜 그걸 하기로 했는지를 잊지 않게 해주는 앱

Future Self는 범용 저널, PKM, 할 일 또는 습관 추적 앱으로 확장하지 않는다.

### 사용자 부담 원칙

- 기록 시 분류, 연결, 목표화, 행동화를 강제하지 않는다.
- 기록이나 Synthesis 저장 자체로 완결된 정상 사용이 될 수 있다.
- `그래서 무엇을 할 건가요`, `가장 작은 행동`, `최소한 이것만`처럼 행동 결정을 압박하는 기본 UX를 사용하지 않는다.
- 분류되지 않은 Meaning Card를 정상적인 영구 상태로 허용한다.
- 미분류 개수, 연결 개수, 그래프 완성도, Inbox Zero를 성취 지표로 사용하지 않는다.
- 사용자의 자기해석이나 정체성 단정을 제품이 교정하거나 판정하지 않는다.

### 의미와 관계

- Motive, Vision, Goal, Practice, Commitment를 다대다로 연결한다.
- 갈등은 `conflicts_with`로 보존한다.
- 사용자가 원할 때만 Trade-off Reflection으로 당시 우선순위와 선택 맥락을 기록한다.
- 앱은 갈등의 정답을 대신 결정하지 않는다.
- 과거 의미와 현재 의미는 revision/event로 함께 보존한다.

### 재노출과 복귀

- 일반 CaptureEntry나 민감한 과거를 임의로 resurfacing하지 않는다.
- Review는 backlog가 아니라 소수의 설명 가능한 후보만 보여준다.
- 장기간 앱을 사용하지 않아도 실패로 취급하지 않는다.
- 복귀 시 밀린 작업을 만들지 않고 사용자가 원할 때만 이전 맥락을 복구한다.
- 공개 승인과 의미 재확인은 별개이다.
- 의미 재확인은 선택 사항이며 주기적으로 강제하지 않는다.

### 잠금화면

- 대표 문장은 사용자 명시 선택으로만 바뀐다.
- 승인된 공개용 Projection revision만 잠금화면에 노출한다.
- 문장 내용 변경은 새 공개 승인이 필요하다.
- 동일 문장의 배경, 위치, 크기 등 시각적 스타일 변경은 재승인을 요구하지 않는다.

### 데이터와 플랫폼

- iOS 우선, React Native Community CLI + TypeScript
- WidgetKit 포함
- local-first
- 수동 암호화 백업과 안전한 복원 제공
- 장기적으로 멀티디바이스 지원
- 동기화 기술은 프라이버시, 오프라인 사용, revision/event 충돌 안전성을 기준으로 구현 전에 기술 검토
- Android는 후속 지원

## 2. AI 결정

**확정: 제품에 AI 기능을 사용하지 않는다.**

따라서 기본 제품에는 다음을 넣지 않는다.

- AI 요약
- AI 검색 보조
- AI 유사 기록 추천
- AI 연결 추천
- AI 질문 생성
- AI Motive, Vision, Goal, Practice, Commitment 생성

검색, 필터, 관계 탐색, Synthesis는 사용자 데이터와 명시적 규칙을 기반으로 동작한다.

향후 AI 기능을 도입하려면 기존 결정의 단순 구현 변경이 아니라 제품 철학 변경으로 간주하고 다시 명시적으로 결정한다.

## 3. 수익화 결정

세부 정책은 `docs/MONETIZATION_POLICY.md`를 따른다.

확정된 방향:

1. 신규 사용자는 1년 무료 체험
2. 공개 출시 후 5주년 전까지는 체험 종료 후 일회성 유료 구매
3. 공개 출시 5주년부터 신규 수익 모델을 구독으로 전환
4. 구독 전환 전에 일회성 구매를 완료한 사용자는 grandfathered lifetime 사용자
5. grandfathered lifetime 사용자는 이후 구독료를 내지 않음
6. 구매 복원을 통해 기기 변경 후에도 entitlement 유지
7. 광고 SDK와 사용자 데이터 판매는 사용하지 않음

StoreKit의 구체 상품 구성은 구현 시 최신 App Store 정책에 맞춰 검증한다.

## 4. 사용자 결정 없이 기본안으로 진행할 항목

### 첫날 경험

- 한 줄 기록만 하고 끝낼 수 있음
- 사용자가 원하면 중요한 문장 하나를 잠금화면에 적용 가능
- 사용자가 원하면 `왜 중요하지?`를 따라 간단한 Why Trail 생성 가능
- 어느 흐름도 강제하지 않음

### 사용 주기

- 순간 사용: 빠른 기록, 현재 문장 확인
- 필요할 때: Why Trail, Synthesis, 의미 재확인, 갈등 검토
- 특정 시점: 회고, 시간 여행, 의미 구조 재검토

매일 접속을 성공 기준으로 삼지 않는다.

### 제품 사용성 검증

외부 Analytics SDK 없이 필요한 로컬 진단만 사용한다. 이 지표는 사용자 점수나 성취로 노출하지 않는다.

## 5. 아직 사용자에게 남아 있는 결정

### 앱 표시 이름

아직 미정이다.

- 저장소 이름 `future-self-lockscreen`은 유지 가능
- 실제 앱 이름은 별도로 정함
- 한국어 이름과 영어 이름을 함께 검토
- 앱 아이콘, 온보딩, App Store 메타데이터를 확정하기 전까지 결정하면 됨

현재 구현 시작에는 영향을 주지 않는다.

## 6. 공개 전에 정하면 되는 상업 설정

다음은 제품 철학 결정이 아니라 출시 설정이다.

- 일회성 구매 가격
- 구독 가격
- 월간, 연간 또는 둘 다 제공할지
- 국가·지역별 가격
- 공개 출시 5주년 시점에 아직 무료 체험 중인 사용자에게 기존 일회성 구매 경로를 유지할지 최종 확정

권장 기본안은 전환 전에 체험을 시작한 사용자가 당시 안내받은 일회성 구매 경로를 유지하도록 하는 것이다.

## 7. 구현 시작 조건

현재 추가 사용자 결정 없이 Phase 1 구현을 시작할 수 있다.

앱 이름과 상업 설정은 해당 공개 단계 전까지 확정하면 된다.
