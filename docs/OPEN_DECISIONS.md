# Future Self Lockscreen 제품 결정 상태

PRD v0.3 기준으로 구현 전에 검토하던 제품 결정을 정리한 문서이다.

## 확정된 결정

### D-01. 1차 대상 플랫폼

**확정: iOS 우선**

공통 도메인과 UI 구조를 먼저 iOS에서 완성한 뒤 Android를 후속 지원한다.

### D-02. iOS WidgetKit의 MVP 포함 여부

**확정: 이미지 생성 + 잠금화면 WidgetKit 포함**

잠금화면에서 지속적으로 문장을 보게 하는 것이 핵심이므로 WidgetKit을 첫 MVP에 포함한다.

### D-03. 여러 메시지가 동시에 활성화될 때

**확정: 잠금화면에는 가장 중요한 메시지 하나만 표시**

무작위 회전은 사용하지 않는다. 고정과 우선순위에 따라 결정론적으로 선택한다.

### D-04. 기본 노출 정책

**확정: 상시 노출**

이 결정은 기존의 “체크포인트 월 전체 또는 30일 전부터 노출” 권장안을 폐기한다.

제품의 핵심은 연말 또는 중요한 회고 시점에 얻은 깨달음을 다음 해 특정 기간에만 보여주는 것이 아니라 일상에서 계속 잊지 않게 하는 것이다.

따라서 회고에서 만든 변화 원칙은 기본적으로 `persistent` 상태가 된다.

사용자가 직접 다음 중 하나를 선택할 때까지 잠금화면 후보로 유지한다.

- 일시 중지
- 종료 또는 보관
- 삭제

특정 월과 날짜는 후속 기능인 `FocusWindow`로 사용한다. FocusWindow는 노출 여부를 결정하지 않고 특정 시기의 우선순위를 높인다.

### D-05. 체크포인트 또는 목표까지 남은 기간 표시

**확정: MVP에서는 홈에 표시 가능하도록 설계하고 잠금화면 표시는 후속 선택 기능으로 둔다.**

잠금화면에서는 변화 원칙 자체가 가장 먼저 읽혀야 한다.

### D-06. 데이터 백업 정책

**확정: 앱 데이터 자동 클라우드 백업 제외 + P1에서 수동 내보내기/가져오기**

개인적인 후회, 목표, 감정이 들어갈 수 있으므로 앱 내부 원문은 기본적으로 기기 내부에 둔다.

사용자가 생성 이미지를 사진 보관함에 저장하면 해당 이미지는 사용자의 iCloud Photos 또는 사진 동기화 설정의 영향을 받을 수 있다. 앱 내부 데이터 백업 정책과 사진 보관함 동기화는 별개이다.

### D-07. React Native 프로젝트 형태

**확정: React Native Community CLI + TypeScript**

Widget Extension, App Group, Android Kotlin 네이티브 모듈을 직접 구성하기 위한 선택이다.

### D-08. 초기 공개 범위

**확정: 본인 사용 MVP로 먼저 완성**

다만 데이터 모델과 화면 문구는 특정 개인이나 편입 시험에 종속하지 않는다.

### D-09. 문장 작성 방식

**확정: 질문형 입력 가이드 + 사용자 직접 작성**

MVP에서는 AI가 후회나 행동 원칙을 대신 생성하지 않는다.

제품은 사용자가 다음 순서로 직접 생각을 구체화하도록 돕는다.

1. 무엇이 후회되는가
2. 무엇을 더 잘할 수 있었는가
3. 왜 그렇게 되었는가
4. 내년에는 무엇을 다르게 하고 싶은가
5. 어떤 행동 원칙을 기억해야 하는가
6. 잠금화면에서 볼 한 문장은 무엇인가

### D-10. 잠금화면 배경 소스

**확정: 단색 배경 + 사용자가 사진 보관함에서 선택한 이미지**

현재 기기의 잠금화면 배경을 앱이 자동으로 읽어 재사용하는 기능은 기본 요구사항으로 두지 않는다.

## 제품 방향 변경 기록

### v0.2까지의 관점

초기 PRD는 과거 후회에 특정 월 또는 노출 기간을 연결하고 해당 기간에 메시지를 활성화하는 구조를 중심으로 설계했다.

### v0.3의 관점

제품의 중심을 다음 구조로 변경한다.

`연말 회고 → 후회와 배움 → 원하는 변화 → 행동 원칙 → 다음 해 상시 노출 → 다음 회고`

중요한 제품 관점은 다음과 같다.

- 1월의 신년계획만으로 행동 변화를 만들려고 하지 않는다.
- 먼저 지나간 한 해를 돌아본다.
- 무엇이 후회되는지 구체화한다.
- 같은 후회를 반복하지 않기 위해 무엇을 바꿀지 정한다.
- 그 변화 원칙을 잠금화면이라는 일상적인 위치에 계속 남긴다.
- 다음 회고에서 실제로 달라졌는지 확인한다.

## 아직 미확정인 결정

### D-11. 실제 앱 표시 이름

저장소 이름은 `future-self-lockscreen`으로 유지한다.

홈 화면과 향후 App Store에 표시할 이름은 아직 확정하지 않았다.

후보 방향:

- Future Self
- Future Self Lockscreen
- 다시 후회하지 않기
- 미래의 나에게
- 회고와 변화를 더 직접적으로 나타내는 별도 이름

이 결정은 UI 디자인을 시작하기 전에 확정하면 된다.

## 구현 시작 가능 여부

현재 제품 구조를 결정하는 핵심 항목은 모두 확정되었다.

앱 표시 이름을 제외하면 구현을 시작하기 위해 추가로 반드시 받아야 하는 제품 결정은 없다.
