# Future Self Lockscreen PRD

- 문서 상태: Draft v0.1
- 작성일: 2026-09-03
- 구현 예정: 2026-09-05 빅데이터분석기사 필기시험 이후
- 기술 방향: React Native + TypeScript

## 1. 제품 한 줄 정의

과거 특정 시기에 반복했던 후회를 현재의 행동 기준으로 바꾸고, 사용자가 스스로에게 해주고 싶은 말을 잠금화면에서 반복적으로 보게 만드는 개인 행동 리마인더 앱이다.

## 2. 배경

사용자는 매년 12월이 되면 “수능을 봤어야 했는데”라는 생각을 반복적으로 해왔다. 사용자는 최근 이 후회가 대학 편입을 반드시 완료해야 하는 개인적인 이유와 연결되어 있다는 점을 인식했다.

이 앱은 막연한 동기부여 문구를 보여주는 앱이 아니다. 사용자가 실제로 겪은 후회와 그 후회에서 도출한 행동 원칙을 기록하고, 미래에 같은 후회를 반복하지 않도록 현재 시점에 필요한 메시지를 잠금화면에서 지속적으로 노출하는 것이 목적이다.

## 3. 해결하려는 문제

### 3.1 핵심 문제

사용자는 중요한 목표를 알고 있어도 일상에서는 장기적인 결과보다 당장의 행동을 우선하기 쉽다. 시간이 지난 뒤에는 “그때 했어야 했다”는 후회를 하지만, 그 후회가 현재의 구체적인 행동으로 연결되지 않는 문제가 있다.

### 3.2 기존 방식의 한계

- 메모 앱에 적은 다짐은 사용자가 직접 열어야 한다.
- 일반 알림은 확인 후 사라진다.
- 명언 앱은 사용자의 실제 경험과 연결되지 않는다.
- 단순 할 일 앱은 “왜 이 일을 해야 하는가”라는 개인적인 맥락을 지속적으로 보여주지 않는다.

## 4. 제품 목표

1. 사용자가 과거의 후회를 구체적인 문장으로 기록할 수 있어야 한다.
2. 사용자가 해당 후회를 다시 하지 않기 위해 현재의 자신에게 할 말을 작성할 수 있어야 한다.
3. 앱은 현재 날짜와 사용자가 설정한 규칙을 기준으로 적절한 메시지를 선택해야 한다.
4. 사용자는 선택된 메시지를 잠금화면에서 반복적으로 볼 수 있어야 한다.
5. 사용자는 앱을 열지 않아도 핵심 메시지를 접할 수 있어야 한다.

## 5. 비목표

MVP에서는 다음 기능을 목표로 하지 않는다.

- SNS 또는 커뮤니티 기능
- 다른 사용자가 작성한 명언 추천
- AI가 사용자의 감정을 분석하는 기능
- 계정 가입 및 클라우드 동기화
- 복잡한 습관 추적 시스템
- 광고 또는 수익화
- 목표 관리 앱 전체를 대체하는 기능

## 6. 핵심 사용자 시나리오

### 시나리오 A. 후회 등록

사용자는 다음 내용을 입력한다.

- 시기: 12월
- 과거의 후회: “올해도 수능을 준비하지 않았다는 생각을 했다.”
- 지금의 나에게 하는 말: “내년 12월에도 같은 생각을 하고 싶지 않으면 오늘 편입 공부를 해야 한다.”
- 행동 원칙: “편입 준비를 미루지 않는다.”

앱은 이 내용을 저장한다.

### 시나리오 B. 잠금화면 메시지 생성

앱은 현재 시점에 보여줄 메시지를 선택한다. 사용자는 잠금화면 레이아웃을 미리 보고 글자 크기와 위치를 조정한다.

사용자가 적용을 선택하면 다음 방식으로 잠금화면에 반영한다.

- iOS MVP: 잠금화면용 이미지를 생성하고 사용자가 사진 또는 배경화면 설정 흐름에서 적용할 수 있게 한다.
- iOS 확장: WidgetKit 잠금화면 위젯에서 짧은 메시지를 표시한다.
- Android: 지원 가능한 OS에서는 잠금화면 배경 이미지로 직접 적용한다.

### 시나리오 C. 월별 메시지 전환

사용자는 여러 시기에 대한 후회를 저장할 수 있다.

예시:

- 3월: “연초 계획을 또 미뤘다.”
- 8월: “시험 직전에 몰아서 공부했다.”
- 12월: “수능을 봤어야 했다고 또 생각했다.”

앱은 해당 월 또는 사용자가 지정한 노출 기간에 맞는 메시지를 우선적으로 보여준다.

## 7. MVP 기능 요구사항

### FR-01. 후회 항목 생성

사용자는 후회 항목을 생성할 수 있어야 한다.

필수 필드:

- 제목
- 관련 월 또는 날짜 범위
- 과거의 후회
- 현재의 자신에게 하는 말

선택 필드:

- 행동 원칙
- 강조할 한 문장
- 노출 시작일과 종료일

### FR-02. 후회 항목 수정 및 삭제

사용자는 저장한 후회 항목을 수정하거나 삭제할 수 있어야 한다.

### FR-03. 현재 메시지 선택

앱은 다음 우선순위로 현재 표시할 메시지를 선택해야 한다.

1. 사용자가 수동으로 고정한 메시지
2. 현재 날짜가 노출 기간에 포함되는 메시지
3. 현재 월과 일치하는 메시지
4. 기본 메시지

### FR-04. 잠금화면 미리보기

사용자는 다음 요소를 조정할 수 있어야 한다.

- 메시지 본문
- 강조 문장
- 글자 크기
- 정렬
- 세로 위치
- 배경 이미지 또는 단색 배경
- 밝은 글자 또는 어두운 글자

시계, 알림 등 OS UI와 겹치지 않도록 안전 영역을 고려해야 한다.

### FR-05. 잠금화면 이미지 생성

앱은 현재 메시지를 포함한 잠금화면용 이미지를 기기 해상도에 맞게 생성할 수 있어야 한다.

생성 이미지에는 다음 항목이 포함될 수 있다.

- 강조 문장
- 전체 메시지 일부
- 날짜 또는 남은 기간
- 사용자가 선택한 배경

### FR-06. 잠금화면 적용

#### iOS

MVP에서는 생성한 이미지를 저장하고 사용자가 iOS의 배경화면 설정 절차에서 적용하도록 안내한다.

추후 WidgetKit 기반 잠금화면 위젯을 추가한다. 잠금화면 위젯은 짧은 문장을 빠르게 확인하는 보조 수단으로 사용한다.

#### Android

네이티브 모듈을 통해 잠금화면 전용 배경 이미지 적용을 지원한다. Android `WallpaperManager`의 잠금화면 플래그를 사용한다.

### FR-07. 메시지 변경 알림

현재 노출해야 할 메시지가 변경되었을 때 사용자가 새 잠금화면을 적용해야 하는 플랫폼에서는 앱이 알림을 제공할 수 있어야 한다.

MVP에서는 알림을 선택 기능으로 제공한다.

### FR-08. 로컬 저장

MVP의 모든 사용자 데이터는 기기 내부에 저장한다. 회원가입과 서버는 사용하지 않는다.

## 8. 화면 구성

### 8.1 홈

목적은 “지금 내가 봐야 할 말”을 즉시 보여주는 것이다.

구성:

- 현재 메시지 카드
- 관련 후회 시기
- 잠금화면 미리보기
- 잠금화면 만들기 버튼
- 메시지 편집 버튼

### 8.2 후회 목록

구성:

- 월 또는 날짜 순 목록
- 제목
- 강조 문장
- 활성 상태
- 추가 버튼

### 8.3 후회 편집

구성:

- 제목
- 시기
- 과거의 후회
- 현재의 자신에게 하는 말
- 행동 원칙
- 강조 문장
- 노출 기간

### 8.4 잠금화면 편집기

구성:

- 실제 화면 비율 미리보기
- 텍스트 위치 조절
- 글자 크기 조절
- 배경 선택
- 적용 또는 이미지 저장

## 10. 기술 방향

### 10.1 공통

- React Native
- TypeScript
- React Navigation
- 로컬 저장소
- 이미지 렌더링 및 저장 기능
- 플랫폼별 네이티브 기능은 별도 모듈로 격리

### 10.2 iOS

잠금화면 위젯은 WidgetKit을 사용해야 하므로 Swift 기반 Widget Extension이 필요하다. React Native 화면과 위젯 사이에서 공유해야 하는 데이터는 App Group 기반 공유 저장소를 검토한다.

MVP에서는 네이티브 위젯 개발 범위를 줄이기 위해 잠금화면 이미지 생성 기능을 우선 구현한다.

### 10.3 Android

잠금화면 배경 직접 적용 기능은 Kotlin 네이티브 모듈로 구현한다. `WallpaperManager`와 `FLAG_LOCK`을 사용하고 필요한 `SET_WALLPAPER` 권한을 선언한다.

### 10.4 플랫폼 경계 원칙

React Native는 메시지 작성, 목록, 편집, 미리보기, 상태 관리 등 공통 UI와 비즈니스 로직을 담당한다.

Swift와 Kotlin 코드는 OS 전용 잠금화면 기능만 담당한다.

## 11. UX 원칙

### 11.1 명언 앱처럼 만들지 않는다

제품의 핵심 콘텐츠는 외부 명언이 아니라 사용자가 실제로 후회했던 경험과 그 경험에서 나온 문장이다.

### 11.2 죄책감을 자극하는 문구를 자동 생성하지 않는다

앱은 사용자가 직접 작성한 문장을 우선한다. 사용자의 의도와 관계없이 공격적이거나 모욕적인 문장을 생성하지 않는다.

### 11.3 잠금화면에서는 짧게 보여준다

잠금화면에서 한 번에 읽어야 하는 내용은 핵심 한두 문장으로 제한한다. 긴 맥락은 앱을 열었을 때 볼 수 있게 한다.

### 11.4 행동으로 연결한다

메시지는 단순한 감정 회상이 아니라 “그래서 오늘 무엇을 할 것인가”로 이어져야 한다.

## 12. MVP 성공 기준

다음 조건을 모두 만족하면 첫 MVP가 완성된 것으로 본다.

1. 사용자가 후회 항목을 하나 이상 저장할 수 있다.
2. 현재 날짜에 맞는 메시지가 자동으로 선택된다.
3. 잠금화면용 이미지를 생성할 수 있다.
4. 실제 휴대전화 잠금화면에서 메시지를 확인할 수 있다.
5. 앱을 종료하고 다시 실행해도 데이터가 유지된다.
6. 네트워크 연결 없이 핵심 기능을 사용할 수 있다.

- 이미지 생성
- 이미지 저장 및 공유

### Milestone 4. 플랫폼 연동

- Android 잠금화면 배경 적용 네이티브 모듈

- 실제 기기에서 글자 가독성 확인
- 시계 및 알림 영역과 겹침 확인
